# Repository Instructions

## UI system

Before creating, editing, or reviewing any user interface, read [`docs/UI_SYSTEM.md`](docs/UI_SYSTEM.md) completely and follow it as the source of truth for this portfolio's design and interaction standards.

Reuse the documented tokens, patterns, and component rules. Do not introduce an exception or change the UI system unless the user explicitly approves it. If a request conflicts with the UI system, identify the conflict before proceeding.
